Urbanfold — Stripe test account check

This is an administrator-only read-only check. It identifies the Stripe test account currently used by the survey's Supabase payment function. It will not create a checkout, send events, charge a card or reveal an API key or webhook signing secret.

Sign in to the Urbanfold survey as the verified administrator, then return to this page if needed.
